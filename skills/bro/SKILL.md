# Bro

## Overview

When activated, fully restate the most recent previous assistant response in a much simpler and clearer form so the user can understand it.

## Instructions

Restate your last message completely.

Follow these rules strictly:

- Stop using jargon. Speak coherently, like one human talking to another.
- Make the rewrite simpler and more concise than the original.
- Use short, clean sentences. Prefer active voice. One clear idea per sentence.
- Keep all paths, commands, code, file names, and technical identifiers exact. Do not change them.
- Structure the rewrite so it stands alone. The user should not need to look at the original message.
- Lead with the core answer or result. Then give the essential supporting details.
- At the end, add a short section called **Key facts** that contains up to 5 very short factual points that capture the most important information from the original response. Each point must be one short sentence or less.

Do not apologize. Do not explain why the original was hard. Just deliver the clearer version.

If the original response contained multiple distinct parts, keep the same logical order but simplify each part.
